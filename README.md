# Draft Ossoff 2028

Неофициальная низовая платформа сторонников, которая просит сенатора Джона Оссоффа баллотироваться в президенты в 2028 году.
*An unofficial grassroots platform asking Sen. Jon Ossoff to run for President in 2028.*

> Сайт не связан с Оссоффом или какой-либо кампанией, и на каждой странице это сказано прямо.

## Как это работает

Лестница участия, от простого к сложному:

1. **«Вы поддерживаете выдвижение Джона Оссоффа?»** — ответ в один клик, без личных данных.
2. **«Скажи Джону, почему»** — 2–3 предложения. ИИ проверяет текст и предлагает более сильную версию. Что публиковать, выбирает автор.
3. **Карточка для соцсетей** (1080×1080). Её публикуют от своего имени, поэтому алгоритмы показывают её охотнее, чем пост страницы.
4. **Личная реферальная ссылка** (`?r=КОД`) считает приведённых друзей.
5–6. Встречи и вручение письма (дальше развивается через email-список).

**Модерация:** оценивается тон, а не точка зрения. ИИ (Claude) выносит вердикт `publish / review / reject`. Пограничные случаи и апелляции уходят живым модераторам. Каждое решение записывается в лог с именем модератора.

**Защита от троллей и ботов:** ИИ-проверка, поиск дублей текста, лимиты по IP (по хешу, сами IP не хранятся), детекторы ссылок-спама и КАПСА, одна история на email, опциональная капча Cloudflare Turnstile.

## Структура

```
site/        статический сайт (GitHub Pages)
  index.html, styles.css, app.js   главная + инструмент историй
  accountability.html              «Corruption & Project 2025»: факты, итоги, план
  admin.html, admin.js             панель модераторов и админов
  config.js                        ← все настройки сайта здесь
worker/      API на Cloudflare Workers + база D1 (schema.sql)
.github/     автодеплой сайта на GitHub Pages
```

Пока `API_BASE` в `site/config.js` пустой, сайт работает в **демо-режиме**: всё кликается, но данные хранятся только в браузере.

## Запуск (≈20 минут, без терминала)

Нужны только два аккаунта: **Cloudflare** (сервер и база данных D1, бесплатно) и **Claude API** (ИИ-модерация). Всё остальное делает GitHub Actions.

### 1. Сайт
Settings → Pages → Source: **GitHub Actions**. Сайт: `https://murad2026.github.io/ossoff/`.

### 2. Ключ Claude API
platform.claude.com → API Keys → Create key, scope **Default workspace**. Поставьте месячный лимит расходов.

### 3. Cloudflare
1. Зарегистрируйтесь на cloudflare.com и один раз откройте **Workers & Pages**, чтобы получить поддомен `*.workers.dev`.
2. Скопируйте **Account ID**.
3. My Profile → API Tokens → Create Token → шаблон **Edit Cloudflare Workers** → добавьте разрешение **Account · D1 · Edit** → создайте токен.

### 4. Секреты в GitHub
Settings → Secrets and variables → Actions → New repository secret:
`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `ANTHROPIC_API_KEY`, `HASH_SALT` (любая длинная случайная строка), `ADMIN_TOKEN` (пароль владельца для панели модерации).

### 5. Деплой
Actions → **Deploy API (Cloudflare Worker + D1)** → Run workflow. Workflow сам создаст базу D1, применит `worker/schema.sql`, задеплоит воркер и покажет его адрес. Этот адрес впишите в `API_BASE` в `site/config.js`, и демо-режим выключится.

### 6. Команда модераторов
1. Откройте `https://…/ossoff/admin.html` и войдите со своим `ADMIN_TOKEN`. Это роль **owner**.
2. Вкладка **Team** → добавьте людей. Каждый получает личный токен, он показывается один раз.
   - **admin** — модерирует посты и управляет модераторами.
   - **moderator** — только модерирует.
3. Удалённый участник сразу теряет доступ. Все действия видны во вкладке **Log**.

### 7. (Желательно) Капча
Cloudflare → Turnstile → создайте виджет. Site key вставьте в `TURNSTILE_SITEKEY` в `config.js`, секрет добавьте в GitHub Secrets как `TURNSTILE_SECRET` и в список secrets в `.github/workflows/deploy-api.yml`.

## Тесты
```bash
cd worker && npm test
```
Тесты проверяют весь API (клик-голос, ИИ-проверку, публикацию, дубли, апелляции, роли модераторов и лог) на имитации базы и Claude, без сети.

## Фото на главной
Положите фото в `site/img/` и пропишите в `config.js`: `HERO_PHOTO: "img/ossoff.jpg"` и строку авторства в `HERO_PHOTO_CREDIT`. Используйте только снимок, на публикацию которого у вас есть права (свой или с открытой лицензией, с указанием автора). Пока поле пустое, на месте фото показывается эмблема со звездой.

## Перед публичным запуском
- Замените `ORG_NAME` и `CONTACT_EMAIL` в `config.js`.
- Если на сайт тратятся деньги (реклама, хостинг сверх бесплатного), в США могут применяться правила FEC о дисклеймерах («Paid for by…»). Уточните у юриста.
- Не используйте фото и логотипы Оссоффа и не пишите от его имени. ИИ-модерация отклоняет выдуманные цитаты.
- Добавьте страницу Privacy Policy: вы храните email-адреса.
